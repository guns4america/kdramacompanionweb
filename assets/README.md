# App screenshots

Upload your screenshots here using **Add file → Upload files** in GitHub.

Suggested filenames (PNG, JPEG, or WebP):

| Filename | App screen |
| --- | --- |
| home.png | Home / Continue Watching |
| spotlight.png | News & Upcoming |
| search.png | Search / Browse |
| discover-filters.png | Mood and genre menu |
| watchlist.png | My List / Completed |
| profile.png | Profile |
| viewing-insights.png | Viewing Insights |
| streaming-preferences.png | Streaming services dialog |
| backup-export.png | Backup, export, and account |

You can upload the existing screenshots you shared in chat. Prefer trimmed images with no personal account information visible. In particular, **redact the email address** in the backup/export screenshot before publishing.

GitHub supports multiple files in one upload. After adding them, commit the upload to `main`.

The current site is fully functional without these assets, and the screenshot gallery can be integrated in the next iteration.
